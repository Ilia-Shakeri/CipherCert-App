# CipherCert UX Guidelines

## Header Pattern
- Use `PageHeader` for major pages.
- Left area: title + subtitle.
- Right area: page actions, with Help icon as the last action.

## Help Placement
- Keep one Help button in the top-right page header actions.
- Tooltip text is always `Help`.
- Help dialog must close via close button and `Esc`.

## Spacing and Layout
- Use `p-8 space-y-8` for page root layout.
- Use glass cards with rounded corners and subtle borders.
- Keep action button spacing consistent (`gap-3`).

## Actions and Messages
- Primary actions: cyan gradient style.
- Secondary actions: subtle bordered style.
- Error actions: red style.
- Use concise toasts with actionable error text.
